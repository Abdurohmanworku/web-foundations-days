About QuickNotes

QuickNotes is a simple web app for jotting down thoughts, reminders and to-dos without any clutter. It is built for people who want to capture an idea fast and find it again later.

How to use QuickNotes

  1. Open the QuickNotes home page.
  2. Type your note into the text area.
  3. Save the note so it appears in your list.
  4. Click a note whenever you want to read or edit it.

Features

  • Create notes in seconds
  • Edit and delete notes at any time
  • Clean, distraction-free layout
  • Keyboard shortcuts for fast writing

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + D Delete the current note
